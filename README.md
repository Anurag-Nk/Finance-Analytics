# Finance-Analytics

# 💰 FinSight – Finance Analysis Dashboard

A dynamic and interactive **Power BI Finance Analytics Dashboard** designed to analyze financial transactions, customer segments, transaction performance, fees, taxes, and regional trends.

---

## 📖 Short Description / Purpose

**FinSight** is an interactive Power BI dashboard that transforms financial transaction data into actionable business insights.

The dashboard provides both **high-level financial performance analysis** and **transaction-level details**, helping users understand transaction trends, customer behavior, revenue distribution, fees, taxes, and transaction status.

---

## 🛠️ Tech Stack

- 📊 **Power BI Desktop** – Dashboard development and interactive visualization.
- 📂 **Power Query** – Data cleaning, transformation, and preparation.
- 🧠 **DAX** – Dynamic measures, KPIs, calculations, and business logic.
- 🗄️ **Data Modeling** – Structured data relationships for cross-filtering and analysis.
- 🎛️ **Interactive Slicers** – Dynamic filtering across multiple dimensions.
- 🔄 **Dynamic Measures** – Metric selection and responsive KPI calculations.

---

## 📂 Data Source

**Source:** Financial Transactions Dataset

The dataset contains transaction-level information covering:

- Transaction ID

- Transaction Type

- Gender
- Customer Segment
- State
- Occupation
- Category
- Total Amount
- Total Fees
- Total Tax

The data was cleaned and transformed using **Power Query** and analyzed using **DAX measures** in Power BI.

# ✨ Features / Highlights

## 📌 Business Problem

Financial organizations generate large volumes of transaction data. Analyzing this data through raw tables makes it difficult to quickly understand financial performance and identify important trends.

Key business questions include:

- How much total transaction value is being generated?
- Which months contribute the highest transaction amounts?
- Which customer segments generate the most value?
- What is the transaction success rate?
- Which states contribute the most transaction value?
- How are transaction amounts distributed across genders?
- Which transaction types generate the highest fees and taxes?

---

## 🎯 Goal of the Dashboard

The primary goal of **FinSight** is to provide an interactive financial analytics solution that:

- Monitors important financial KPIs.
- Tracks transaction performance over time.
- Analyzes customer segments.
- Compares state-wise financial activity.
- Monitors transaction status.
- Analyzes fees and taxes.
- Provides detailed transaction-level information.
- Supports data-driven financial decision-making.

# 📊 Dashboard Walkthrough

## 1️⃣ Overview Analysis

The **Overview Analysis** page provides a high-level view of financial performance.

### 🔑 Key KPIs

- 💰 **Total Amount**
- 🔄 **Total Transactions**
- 📊 **Average Transaction Value**
- 💵 **Total Fees**
- 🧾 **Total Tax**

Each KPI includes a **year-on-year comparison** to help monitor changes in financial performance.

### 📈 Key Visuals

#### Total Amount by Month

Shows monthly transaction value and helps identify periods of high and low financial activity.

#### Total Amount by Transaction Status

Breaks down transaction value into:

- Success
- Failed
- Pending

This helps monitor transaction performance and identify potential operational issues.

#### Total Amount by Customer Segment

Compares financial activity across:

- Retail
- Premium
- SME
- Corporate
- Wealth

#### Total Amount by State

Provides a regional comparison of transaction values across different states.

#### Transaction Type Analysis

Compares:

- Transaction Amount
- Fees
- Tax
- Number of Transactions

across different transaction types.

#### Total Amount by Gender

Analyzes transaction value distribution between male and female customers.

### 📋 Transaction Details

- Transaction Type
- Transaction Status

- State

## 🎛️ Interactive Filters

The dashboard includes dynamic filters for:
